
# CNR‑Kochrezepte – für Android
![Kochrezepte_Logo](app/src/main/res/drawable/app_logo.png)

CNR‑Kochrezepte ist eine moderne native Android‑App zur Verwaltung von Kochrezepten.
Die Anwendung ermöglicht das Erfassen, Organisieren, Filtern und Exportieren von Rezepten – vollständig offline und ohne Server.

> ⚠️ **Hinweis:** Diese App dient ausschließlich zur privaten Verwaltung von Rezepten.
